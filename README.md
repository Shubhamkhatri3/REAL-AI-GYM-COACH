# 🏋️ AI Real-Time Gym Coach

An AI-powered fitness assistant that analyzes your workout in real time using computer vision and provides instant feedback.

## 🚀 Features

* Real-time pose detection
* Exercise tracking (Squats, Push-ups, etc.)
* AI-based form correction
* Voice feedback using TTS
* Workout history tracking

## 🧠 Tech Stack

* Python
* Streamlit
* MediaPipe / OpenCV
* Groq API
* SQLite

## 🔐 Setup

Create a `.env` file:

GROQ_API_KEY=your_api_key_here

## ▶️ Run

streamlit run main.py

## ⚠️ Note

* Do not upload `.env` to GitHub
* Add your API key in environment variables for deployment
